# 漫画风讲解（知识点、课程）

样例：一元二次方程漫画讲解（60 秒，7 场）。做过一支之后，同类视频直接复制那个项目改内容，比从产品介绍模板改更快。

## 画面语言

| 元素 | 做法 |
|---|---|
| 纸面 | 奶油底 `#FFF4DA` + 朱红半调网点（`radial-gradient` 24px 网格，随 t 缓慢平移） |
| 分镜格 | 白底、6px 墨线、12px 实心偏移投影、每格 ±1° 微倾；落下时从 1.3 倍、多转 6° 砸下，同时整个画面衰减抖动 0.4 秒 |
| 旁白框 | 左上角黄底黑框名词标题（定义 / 因式分解法 …），从左侧弹入 |
| 对白 | 圆角气泡 + SVG 尾巴（白色三角盖住气泡底边，只描两条斜边）；按整句先量宽度再逐字打出，气泡不抖；同一场里下一句开始时上一句收起 |
| 角色 | 内联 SVG（小宇、猫老师），说话时嘴型 12 次/秒开合，每 3.3 秒眨眼，轻微呼吸起伏；反应动作：摇头抖动、跳起 + 背后爆炸星 |
| 公式 | 逐块写出（每块从 1.5 倍、上方 18px 落下），分数线、根号横线用 `scaleX` 从左画出；a / b / c 全片固定红 / 蓝 / 绿 |
| 强调 | 盖章（2.4 倍砸下）、红色大叉、答案黄底描边高亮、集中线（放射三角 + 椭圆遮罩淡出，每 0.125 秒抖 0.4°） |
| 图形 | 抛物线用 `pathLength="1"` + `stroke-dashoffset` 画出，交点红点弹出 |
| 字体 | 中文站酷快乐体（OFL，GitHub google/fonts 仓库 `ofl/zcoolkuaile` 下载 TTF 放 assets）；公式数字 Arial Rounded MT Bold，字母 Georgia 粗斜体 |

## 版式

- 16:9，左侧 1230px 宽放分镜格（x 70–1300），右下角常驻两个角色（小宇在左、猫老师在右），气泡在角色上方，尾巴指向说话人。
- 开场单独一版：满屏旋转放射线 + 描边大标题 + 红色丝带 + 两个大角色。
- 收尾：三张步骤卡 + 「搞定！」拟声字盖章。

## 声音

- 配乐：C 大调 C–Am–F–G，「嘭-恰」弹跳（低音 1、3 拍，短和弦 2、4 拍）+ 钟琴旋律 + 轻鼓，收尾 F–G–C 解决。
- 对白嘀嘀：每个字一声（跳过空格和标点），三次谐波方波感短音，五声音阶随机音高；猫老师低八度、小宇高，左右声像分开。
- 公式落笔「嗒」、分镜落下闷响 + 纸张拍击、盖章重击 + 咔嚓、弹出上滑音、答对「叮」、打叉「嘣——」弹簧音、抛物线口哨滑音、转场嗖。
- 软限幅推动量 `DRIVE = 2.4`，约 -15 LUFS。

## 分镜节奏（60 秒 7 场）

开场 5.5s → 定义 9s → 生活例题 9s → 解法一 10s → 解法二 11s → 判别式 10s → 总结 5.5s。每场一个知识点，结论先由角色对白抛出问题，再由画面给答案。

## 唯美水彩变体（绘本 / 浪漫向知识点讲解）

样例：牛顿第一定律（60 秒，7 场）。

同一套分镜机制，把「朱红半调 + 6px 粗墨线 + 实心偏移影」换成「奶油底 + 细墨线 + 淡彩」，观感从漫画转为唯美绘本。机制、数据属性自校验、时间轴结构全部不变，只改样式与素材。

| 元素 | 做法 |
|---|---|
| 纸面 | 奶油 `#FBF7F1` + 极淡淡紫网点（`rgba(154,143,204,.17)`，26px 网格）；`#stage` 用 158° 三段线性渐变（奶油 → 米 → 淡紫），不用半调色块 |
| 墨色 | 柔墨 `#3B3543`（不用纯黑），描边从 6–7px 降到 3–3.4px |
| 分镜格 | 白底 `#FFFDFA`、3px 柔墨线、圆角 16px；阴影改成「大范围柔和投影 + 5px 小偏移」，不用 12px 实心偏移影；微倾从 ±1° 收到 ±0.7° |
| 角色 | 内联 SVG 细线水彩：角色背后垫一层柔白椭圆光晕（`opacity: .78`），压在满屏插画上也读得清；嘴型 / 眨眼 / 呼吸逻辑原样保留 |
| 插画 | AI 生图放 `assets/`；分镜格内 `object-fit: cover`，整场做 Ken Burns 缓慢推近 |
| 满屏开场 | 插画 `inset:-30px` 铺满 + 薄罩层 + 描边大标题 + 丝带 |
| 强调 | 荧光笔扫过关键词（见下） |
| 字体 | 同上，站酷快乐体 |

### 运镜与罩层（最容易做坏的两处）

- **Ken Burns 必须线性推进**：`p = clamp((t - scene.start) / (scene.end - scene.start))`，缩放 `1 → 1.05~1.07`。用 `E.out` 缓出的话前 1 秒就推完了，后段几乎不动，白做。
- **满屏插画的罩层要薄**：`.12 / .38 / .62` 的三段径向 + 上下两条轻压角渐变就够。淡彩插画本身明度就很高，罩层一厚整场发灰、插画几乎看不见（首版用了 `.40/.74/.88`，画面糊成一片白，返工）。淡彩图可以再补 `filter: contrast(1.06) saturate(1.05)` 提一点对比。

### 荧光笔扫关键词

`background-image: linear-gradient(transparent 58%, 黄 58%)` + `background-repeat: no-repeat`，用 `background-size: N% 100%` 从左扫出（`N` 由 `P(t, 起, 止)` 驱动）。`.tk` 是 `inline-block`，背景直接生效，比画 `<rect>` 省事。用于定律里「没有受到力的作用时」「匀速直线运动状态」这类必须一眼看到的关键短语。

### 插画用自己的生图通道批量出，不要用宿主工具内置的生图

- 用自己的生图接口批量出（作者用 gpt-image 系模型，4K、3:2），**无水印**。
- **不要用宿主工具内置的生图出插画**：常扣平台额度，还可能压「AI 生成」之类的水印。7 张图全出完才发现水印，只能整批重做。
- `tasks.tsv` 每行 `文件名.png<TAB>提示词`；提示词末尾强制加一句「绝对不要出现任何文字、字母、数字、刻度、符号或水印」——AI 图很容易在路面、黑板、招牌上乱写字。
- 出图后用 `ocr-to-text` 反查是否混进乱码文字。
- 批量出完按分辨率逐张校验，降质的换文件名重出，不覆盖。

## 配音 + 字幕

- `tts.js` 按 `TL.voice.lines` 逐句合成，拼成 `out/voice.wav`，同时生成 `voice.js`（每句 `at / dur / text`）。
- 页面里字幕层 `#subtitle > span` 由 `renderSubtitle(t)` 按 `voice.js` 时间轴显隐，样式做成漫画旁白框（黄底墨线）。
- **字幕数据必须每帧从 `window.VOICE` 现取，不要在 init 时存成局部 `const`**：`cover.js` 出封面的手法是把 `window.VOICE = null` 来关掉字幕层，存成常量后置空无效，封面底下会压一条字幕。写成 `if (src !== subsSrc) { 重建 }` 的惰性缓存即可。
- 字幕留出底部安全区：`.panel` 底边 940px、`#subtitle` 顶边约 998px，58px 间隙，各场版式按这个余量排。
- 改配音后 `node render.js --mix` 秒出，不必重拍画面。
- `tts.js --check` 用 whisper 回听比对（字级 LCS 相似度 ≥ 85% 判「通过」）。转写服务上游会整体饱和、连续重试失败并中断整轮——这是**转写服务**的问题、不是配音的问题。务必用带**识别缓存**（`out/voice/<id>-<hash>.txt`）＋**单句失败只跳过不中断**的 `tts.js` 版本，饱和时重跑能接着上次继续，不会每次都从第 1 句重来。（模板里的 tts.js 还没有识别缓存，需要时自己加。）

## 两个体检坑

- **`subcheck.js` 判可见性必须逐级向上查祖先**：分镜格还没落下时自身 `opacity: 0`、`scale(1.3)`（`renderAnims` 在 `t < t0` 时给的就是起手值），但**子元素自己的 opacity 仍是 1**。只查元素自身，就会把「没落下的格子旁边那些隐形的图」算成与字幕重叠，报假阳性。正确做法是从元素一路 `parentElement` 查到 `body`，任一祖先 `display:none` / `opacity < 0.35` 就直接跳过。
- **Bash 沙箱里 `ffmpeg` / `ffprobe` 常在 `/opt/homebrew/bin` 却不在 PATH**，脚本前先 `export PATH="/opt/homebrew/bin:$PATH"`，否则 `render.js` / `tts.js` 会以 `ffmpeg not found` 失败。
