# 场景套路

全部来自样片（`template/`），代码在 `scenes.js` 对应的 `R.sX` 里，拿来改文案和元素即可。时间都是样片里的绝对秒数，照搬时按新场景起点平移。

## 通用工具（scenes.js 顶部）

| 工具 | 用法 |
|---|---|
| `P(t, a, b, ease)` | a→b 区间的 0–1 进度，默认 `E.out`（三次缓出） |
| `E.out5` / `E.back` / `E.inOut` / `E.in` | 大元素入场用 out5，弹出用 back（带回弹），鼠标移动用 inOut，离场用 in |
| `up(el, t, t0, d, dist)` | 淡入 + 上移入场，最常用 |
| `set(el, {o, x, y, s, sx, blur})` | 一次写 opacity / transform / filter |
| `bump(t, c, d)` | c 时刻起 d 秒的 0→1→0 脉冲，做按下回弹 `scale(1 - 0.12 * bump(...))` |
| `typed(key, t)` / `typingEnd(key)` | 读 timeline 的打字配置，返回此刻已打出的文字 |
| `caretOn(t, from, activeUntil)` | 打字中常亮，停下后每 0.5 秒闪烁 |
| `enterSide(root, t, t0)` | 左栏四行依次上浮 + 右侧窗口从右滑入（x 90→0，缩放 0.97→1） |

场景切换：每个场景最后 0.35s 淡出并上移 24px、缩到 0.98；下一个场景的元素从起点开始各自入场，中间留一瞬纸面底色，配转场嗖声。开场与收尾整场景加极慢放大（每秒 0.5%）。

## 1. 开场品牌（0–5.5s）

标语逐字入场（每字错开 0.07s，带 8px 模糊到清晰）→ 1.85s 标语上移缩小成小标题 → 2.0s 品牌字标从遮罩下方升起（`overflow:hidden` 容器 + translateY 100%→0，out5）配重音 → 2.6s 朱红短横条从中间展开 → 3.0s 定位语淡入。

## 2. 左栏说明 + 右侧产品窗口（功能场景通用骨架）

- 左栏：编号（朱红小字 01）/ 名词标题 88px / 一句说明 36px / 3–4 个胶囊标签。
- 右侧：1020×740 白色窗口，顶部 48px 栏（三个灰点 + 居中网址胶囊 `<产品域名>/xxx`），窗口内按真实产品界面仿做。
- 左上角常驻小字标（功能场景期间显示）。

## 3. 下拉切换（样片：多模型对话）

鼠标到胶囊 → 点击（胶囊回弹）→ 下拉向上展开（行错开 0.03s 淡入）→ 高亮条随鼠标从当前项滑到目标项 → 点击 → 勾选切换、下拉收起 → 胶囊里旧名上移淡出、新名从下方升入 → 输入框打字 → 鼠标移到发送键点击。

## 4. @ 调用与筛选（样片：智能体）

打出「@」时下拉出现 → 继续打字，不匹配的行高度收到 0 并淡出（真实改 height，布局跟着收）→ 目标行底色变灰（悬停）→ 点击 → 输入框里的「@小红」替换成带头像的彩色标签（back 弹出）→ 继续打字 → 发送 → 下方出现「XX 正在写作」和三个呼吸圆点（相位错开 0.22）。

## 5. 对话写作 + 流式落稿 + 划词（样片：创作编辑器）

左栏对话：用户气泡 → AI 说明 → 版本卡。右栏正文：标题和各段按一条连续字流写入（24 字/秒），光标元素每帧移到当前段末尾。写完后鼠标从选区起点拖到终点，选区底色用 `background-size: p*100% 100%` 同步扫过，松手后黑色浮动菜单（改写 / 扩写 / 缩写 / 润色）弹出。

## 6. 出图（样片：AI 生图工作台）

打字 → 点发送 → 瀑布流卡片先以加载态出现（浅灰流光 + 「生成中 N%」，百分比由 t 线性算）→ 按间隔 0.35s 依次揭晓：图片从 18px 模糊、放大 1.08 回到清晰、原尺寸，加载层淡出，每张配一个「啵」。

## 7. 卡片网格（样片：专家工作台）

六张卡错开 0.12s 用 back 弹出（y 30→0，缩放 0.9→1）→ 鼠标依次悬停三张，被悬停的卡上浮 10px、阴影加深、描边加深（悬停窗口写成 `{卡片序号: [进入, 离开]}`）。

## 8. 能力总览 + 汇聚转场

标题上浮 → 六个图标错开 0.1s 弹出 → 最后 0.65s 所有图标向中心收拢（x 偏移 = -(i - 2.5) × 间距 × c）、缩到 0.2、淡出，配升调铺垫，直接接收尾。

## 9. 收尾 CTA

品牌字标 14px 模糊 + 1.08 缩放到清晰（配重音）→ 定位语 → 黑色网址胶囊 back 弹出 → 注册福利一行（数字朱红）→ 鼠标移到胶囊右侧点击（不要挡住网址文字）→ 定格到结束，音乐最后 2 秒淡出。
