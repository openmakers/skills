# 音频配方（audio.js）

纯 Node 实现，不依赖 numpy / 音频库：Float32Array 做总线，逐采样合成，最后写 16bit WAV。45 秒立体声 48kHz 约 2 秒算完。

## 结构

| 段落 | 编配 |
|---|---|
| 开场（0–5.5s） | 和弦铺底 + 四分音符琶音，无鼓；2.0s 重音 |
| 功能段（5.5–39s） | 铺底 + 八分音符琶音 + 八分贝斯 + 底鼓每拍 / 拍手 2、4 拍 / 踩镲反拍，底鼓压缩音乐总线 |
| 总览收束 | 38.3–39.5s 升调铺垫，39.0s 鼓停，给重音留空 |
| 收尾 | 39.5s 重音，铺底 + 四分琶音，最后一小节停在 Fmaj9 长音，43–45s 淡出 |

和弦（F 大调，每小节一个）：Fmaj7 → Am7 → Dm7 → B♭maj7 循环；倒数第二小节 B♭maj7，最后 Fmaj9 解决。

## 音色

| 声部 | 做法 | 增益 |
|---|---|---|
| 铺底 | 每音 3 个失谐 ±8 音分的锯齿（6 次谐波加法），起音 0.45s，释音 0.9s，1600Hz 低通 | 每声部 0.03 |
| 琶音 | FM：`sin(2πft + I·e^(-14t)·sin(2π·2f·t))`，衰减 e^(-7t)，左右交替 ±0.35，混响发送 0.5 | 0.16–0.2 |
| 贝斯 | 正弦 + 0.35 倍二次谐波，0.24s 一个音，每小节第 4、8 个八分音高八度 | 0.3 |
| 底鼓 | 正弦扫频 155→45Hz（e^(-30t)），衰减 e^(-8t)，开头 4ms 噪声做敲击感 | 0.75 |
| 拍手 | 1500Hz 带通噪声，双击包络（0 与 11ms） | 0.55 |
| 踩镲 | 7000Hz 高通噪声，e^(-70t) | 0.16 |
| 压缩 | 每个底鼓处音乐总线乘 `1 - 0.45·e^(-9t)` | — |

## 音效

| 音效 | 做法 | 增益 |
|---|---|---|
| 点击 | 2400Hz（e^(-260t)）+ 1100Hz（e^(-110t)）+ 极短噪声 | 0.42 |
| 打字 | 3000Hz 高通噪声（e^(-380t)）+ 1700–2600Hz 随机正弦，音量与声像随机 | 约 0.1 |
| 转场嗖 | 带通噪声中心频率 300→2900Hz 扫，sin 包络，峰值落在切换点前 | 0.55 |
| 弹出 | 正弦 520Hz 上滑，e^(-32t) | 0.2 |
| 重音 | 40Hz 下扫的低频冲击（e^(-2.6t)）+ 高八度 FM 钟声和弦 + 前 0.8s 反向高通噪声 | 0.75 / 0.09 / 0.22 |
| 升调 | 带通噪声中心 400→6000Hz，音量平方上升 | 0.45 |

混响：Schroeder（4 个梳状 1687/1601/1867/1777 采样，反馈 0.82，阻尼 0.3；2 个全通 556/241，g=0.5），右声道延迟 700 采样拉宽。母带：音乐与鼓先乘淡出，再加音效，`tanh(1.1x)` 软限幅，峰值归一到 0.89（约 -1 dBTP），整体约 -13 LUFS。

## 调整建议

- 想更安静：把归一目标 0.89 降到 0.8，约 -14 LUFS。
- 想更科技感：BPM 128、和弦换 Am7 → Fmaj7 → Cmaj7 → G，琶音改十六分。
- 想更温和：去掉拍手，底鼓只在 1、3 拍，压缩深度 0.45 → 0.25。
- 所有随机都用固定种子（`rand()`），同一份时间轴每次合成结果完全一致。
