# 双人对白写稿

播客感来自「两个人真的在聊」，不是一份稿子拆成两半念。写之前先想清楚这期要让听众带走哪 3–5 个观点，每个观点一章。

## 两个角色

| 角色 | 字段 | 职责 | 常见句式 |
|---|---|---|---|
| 主持（a） | `who: 'a'` | 替听众发问、复述、表态、收束 | 「为什么叫……？」「那反过来呢？」「听起来像……」「所以说……」「能举个例子吗？」 |
| 嘉宾（b） | `who: 'b'` | 给观点、给例子、给数字 | 「一句话概括：……」「原因是……」「举个例子：……」 |

- a 的句子短（5–15 字），b 的句子长一些（15–45 字）。a 一长就变成两个讲师。
- a 每章至少一次「替听众质疑」或「替听众总结」，这是播客和单人朗读最大的区别。
- b 讲完一个抽象观点，紧跟一个具体例子（跑鞋放门口、手机响了），例子比定义好记。

## 结构

| 段落 | 句数 | 写法 |
|---|---|---|
| 开场 | 2 句 | a 报节目名和书名；b 一句话概括全书 |
| 每章 | 3–4 句 | a 抛问题 → b 观点 → a 追问或复述 → b 例子 / 结论 |
| 收尾 | 2–3 句 | a 感受式总结；b 给一个今天就能做的行动；a 道别 |

章节数：90 秒 4–5 章，3 分钟 6–8 章，10 分钟按书的主干分 10 章左右，每章 2–3 个回合。

## 时长

MiniMax speech-2.8-hd 实测约 **5.3 字 / 秒**（含标点停顿），加上换人停顿：

| 目标时长 | 对白总字数 | 句数 |
|---|---|---|
| 60 秒 | 约 280 字 | 12–14 |
| 90 秒 | 约 430 字 | 18–20 |
| 3 分钟 | 约 900 字 | 36–40 |

写完先跑 `node tts.js` 看全片时长，超了删句子，不要靠加快语速压时间。

## 字幕友好

- 每句最好不超过 45 字；超过的长句在逗号、分号处会自动分页，但一页最多 30 字。
- 一句话里的分句（逗号之间）尽量 4–15 字，分页才会落在自然停顿上。
- 数字写成汉字：「每天进步百分之一，一年后是三十七倍」。读法可控，字幕也统一。
- 英文书名、人名放在作者栏，不放进对白（合成会读得生硬）。

## 要点卡

每章 1–2 张，挂在说出这个要点的那句台词上（`at: 'l4'`），比台词早半拍出现会抢话，晚一句出现就跟不上。

- 内容是画面替耳朵记的东西：公式（`1.01<sup>365</sup> ≈ 37.78`）、口诀（目标定方向 · 系统定进步）、并列词（显而易见 · 有吸引力）。
- 单行不超过 14 个汉字，两行用 `<br>`；超过 860px 宽模板会报错。
- 不放整句台词，字幕已经有了。

## 讲书的分寸

- 只概述观点、用自己的话讲，不大段引用原文；书里的例子可以换成本地化的（华氏度换摄氏度、美国场景换中国场景）。
- 对白里说书名，画面上写原作者和中译本书名。
- 有争议或简化过的说法，让 b 用「书里认为」「作者的说法是」带出来。

## 样例（原子习惯，节选）

```js
{ id: 'l3', who: 'a', text: '为什么叫原子习惯？', gap: 0.5 },
{ id: 'l4', who: 'b', text: '原子很小，能量却很大。习惯也一样，每天进步百分之一，一年后是三十七倍。' },
{ id: 'l5', who: 'a', text: '那每天退步百分之一呢？' },
{ id: 'l6', who: 'b', text: '会缩到只剩零点零三。差距，就藏在每天那一点点里。' },
```

对应的章节与要点卡：

```js
{ id: 'c1', title: '复利效应', from: 'l3', keys: [{ at: 'l4', text: '1.01<sup>365</sup> ≈ 37.78' }, { at: 'l6', text: '0.99<sup>365</sup> ≈ 0.03' }] },
```
